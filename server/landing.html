Set up in a minute
no account needed.

Sinehan isn't on the Chrome Web Store yet, so it's added by hand. It only takes three steps.

Install
01Download the zip and unzip it somewhere you'll keep it, like Documents.
02Open chrome://extensions, turn on Developer mode, then Load unpacked and pick the sinehan folder.
03Pin Sinehan, open a show and click the link icon in the sidebar. Send it to the other person.
